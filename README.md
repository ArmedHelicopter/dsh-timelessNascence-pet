# dsh-timelessNascence-pet

Timeless Nascence（Nascence）主题的 DeepSeek Harness 桌宠 + 皮肤。

| 目录 | 内容 |
|---|---|
| `pet/` | `dsh-nascence-pet` 桌宠插件（状态机/气泡/计费提示，代码派生自 MIT 的 dsh-closure-pet） |
| `skin/` | `dsh-nascence-skin` 客户端皮肤（CRT + 星野配色，派生自 MIT 的 dsh-closure-skin） |
| `art/design/` | 角色设定、动作表、代码任务说明 |
| `art/prompts/` | Flow（Nano Banana）出图提示词 |
| `art/keyframes/` | 生成的关键帧原图 |
| `art/voice/` | Gemini 产出的人格分析 `persona.md` 与台词 `dialogues.json` |
| `art/tools/` | 参考板、本地接收服务等工具脚本 |
| `reference/`, `videoreference.mp4` | 角色参考素材（仅供本地创作参考，不随插件分发） |

角色形象与参考素材的权利归原作者所有；插件代码为 MIT。
